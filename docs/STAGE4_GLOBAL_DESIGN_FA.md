# استیج ۴ Woact — طراحی سراسری و Style Preset

نسخه `1.0.2-rc1` یک Design System واقعی در سطح سند صفحه اضافه می‌کند. این سیستم از تب «سراسری‌ها» در پنل المان‌ها مدیریت می‌شود و خروجی آن بخشی از JSON صفحه است.

## ده ورک انجام‌شده

1. پنل زندهٔ طراحی سراسری در کنار ابزارک‌ها
2. رنگ‌های سراسری نام‌دار
3. تایپوگرافی‌های سراسری نام‌دار
4. مقیاس فاصله‌های مشترک
5. شعاع گوشه‌های مشترک
6. سایه‌های مشترک
7. Style Preset ترکیبی و کلاس CSS
8. اتصال هر المان به Token یا Preset
9. Breakpointهای قابل تنظیم و CSS سراسری صفحه
10. ذخیره امن، قرارداد JSON هوش مصنوعی و Renderer مشترک

هر المان می‌تواند علاوه بر تنظیمات محلی، `colorToken`، `backgroundToken`، `typographyToken` یا `globalStyle` داشته باشد. تنظیم محلی روی مقدار Preset اولویت دارد. Renderer متغیرهای CSS با پیشوند `--woact-*` نیز تولید می‌کند.

تغییر یک Token در پنل «سراسری‌ها» بلافاصله تمام المان‌های متصل را در بوم React به‌روزرسانی می‌کند.
