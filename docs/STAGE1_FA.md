# استیج ۱ Woact — قالب React با مهاجرت تدریجی

نسخهٔ این استیج `0.1.0-rc1` است. خروجی شامل قالب `woact` و افزونهٔ همراه `woact-core` است.

## تصمیم اصلی

Woact در شروع سایت‌های موجود را مجبور به React نمی‌کند. تنظیم پیش‌فرض «ترکیبی» است:

- نوشته‌ها، صفحات Gutenberg، صفحات Elementor، خروجی shortcodeها و قالب‌های افزونه‌ها با مسیر عادی WordPress اجرا می‌شوند.
- در ویرایش هر نوشته یا صفحه، جعبهٔ «نحوه نمایش Woact» وجود دارد و می‌توان همان صفحه را روی React قرار داد.
- پس از آماده‌شدن ویجت‌ها و صفحه‌ساز Woact، حالت سراسری را می‌توان روی React گذاشت.
- در حالت سراسری React نیز صفحات شناسایی‌شدهٔ Elementor، Divi، Beaver Builder، WPBakery، Bricks، Breakdance، Oxygen و Avada به‌طور خودکار کلاسیک می‌مانند؛ انتخاب صریح React برای همان صفحه این حفاظت را لغو می‌کند.
- حالت «وردپرس و صفحه‌سازها» کل سایت را فوراً به رندر کلاسیک برمی‌گرداند و نقش کلید ایمنی را دارد.

## حالت‌های رندر

| حالت | رفتار |
|---|---|
| وردپرس و صفحه‌سازها | همهٔ درخواست‌ها با template و hookهای WordPress اجرا می‌شوند |
| ترکیبی | رندر WordPress پیش‌فرض است؛ React برای هر محتوا جداگانه فعال می‌شود |
| React سراسری | انواع محتوای انتخاب‌شده React هستند؛ صفحات صفحه‌ساز محافظت می‌شوند |

## مسیر داده

1. WordPress درخواست و Query اصلی را می‌سازد.
2. `woact-core` بر اساس تنظیم سراسری، انتخاب صفحه، نوع محتوا و تشخیص صفحه‌ساز، حالت نهایی را تعیین می‌کند.
3. در حالت کلاسیک، template انتخاب‌شدهٔ WordPress، Elementor یا افزونه بدون تغییر اجرا می‌شود.
4. در حالت React، قالب `react-shell.php` بارگذاری می‌شود.
5. دادهٔ اولیهٔ نسخه‌دار شامل سایت، مسیر، منو و محتوا در صفحه قرار می‌گیرد.
6. برنامهٔ React با `wp-element` خود WordPress mount می‌شود و خروجی اولیهٔ HTML را جایگزین می‌کند.

استفاده از `wp-element` باعث می‌شود React جداگانه و تکراری به سایت اضافه نشود و نسخهٔ React مدیریت‌شدهٔ WordPress استفاده شود.

## نصب

از پوشهٔ پروژه دستور `npm run package` را اجرا کنید.

سه فایل در پوشهٔ `build` ساخته می‌شود:

- `woact-theme-0.1.0-rc1.zip`
- `woact-core-0.1.0-rc1.zip`
- `woact-stage1-0.1.0-rc1.zip`

ابتدا ZIP قالب و سپس ZIP افزونه را از پیشخوان WordPress نصب کنید. پس از فعال‌سازی افزونه، از منوی «Woact» حالت رندر را مدیریت کنید.

## معیار پذیرش

- قالب بدون افزونه نیز فعال می‌شود و در حالت کلاسیک کار می‌کند.
- با فعال‌شدن افزونه، حالت ترکیبی پیش‌فرض است.
- صفحهٔ Elementor به‌طور خودکار با خروجی Elementor نمایش داده می‌شود.
- صفحهٔ معمولی را می‌توان از جعبهٔ ویرایش روی React قرار داد.
- حالت کلاسیک همهٔ انتخاب‌های React را به‌عنوان کلید ایمنی متوقف می‌کند.
- منو، نوشته، صفحه، آرشیو، جست‌وجو و 404 در مسیر پایه پشتیبانی می‌شوند.
- RTL، منوی اصلی، لوگو، تصویر شاخص، دیدگاه‌ها و قابلیت‌های پایهٔ WooCommerce ثبت شده‌اند.
- بستهٔ تولیدی در زمان اجرا به Node.js نیاز ندارد.

## محدودهٔ این نسخه

محتوای صفحه در حالت React هنوز به‌صورت HTML پالایش‌شدهٔ WordPress داخل یک کامپوننت React قرار می‌گیرد. تبدیل بلوک‌ها، Elementor JSON و ویجت‌ها به کامپوننت‌های کاملاً بومی React در استیج‌های ۴ و ۵ انجام می‌شود. قرارداد فعلی اجازه می‌دهد صفحات به‌تدریج به آن ساختار منتقل شوند.
