# ساخت هدر و فوتر Woact با هوش مصنوعی

از نسخهٔ `0.3.1-rc1` سازندهٔ Woact می‌تواند یک بستهٔ JSON شامل هدر و فوتر را هم‌زمان وارد کند. فایل نمونه از نوار پایین سازنده با دکمهٔ «نمونه JSON هوش مصنوعی» دریافت می‌شود.

## روش پیشنهادی

1. فایل نمونه را دانلود کنید.
2. فایل را همراه توضیح ظاهر مطلوب خود به مدل هوش مصنوعی بدهید.
3. دکمهٔ «کپی پرامپت AI» را بزنید و متن کپی‌شده را نیز به مدل بدهید.
4. از مدل بخواهید فقط JSON معتبر برگرداند و ساختار، نام نوع‌ها و `schemaVersion` را عوض نکند.
5. JSON تولیدشده را از «درون‌ریزی» وارد کنید. هدر و فوتر به‌صورت دو پیش‌نویس غیرفعال ساخته می‌شوند تا ابتدا آن‌ها را بررسی و سپس منتشر کنید.

## قرارداد اصلی

- ریشهٔ فایل باید `product: "woact-layout-bundle"` و `schemaVersion: 2` داشته باشد.
- `templates` آرایه‌ای از حداکثر ۲۰ قالب است.
- نوع هر قالب فقط `header` یا `footer` است.
- شناسه‌های ردیف، ستون و عنصر باید یکتا و شامل حروف انگلیسی، عدد، خط تیره یا زیرخط باشند.
- رنگ‌ها باید Hex شش‌رقمی باشند.
- عرض هر ستون عددی بین ۱ تا ۱۲ است.
- فایل واردشده عمداً فعال یا منتشر نمی‌شود؛ انتشار فقط با اقدام مدیر انجام می‌شود.

Woact ورودی را در سمت سرور پاک‌سازی می‌کند؛ نوع عنصر یا Shape ناشناخته حذف یا به مقدار امن تبدیل می‌شود.
