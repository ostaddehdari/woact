# استیج ۲ Woact — موتور تنظیمات React

نسخهٔ این استیج `0.2.0-rc1` است. تنظیمات سادهٔ استیج اول به یک موتور تنظیمات نسخه‌دار و قابل توسعه تبدیل شده است.

## امکانات اصلی

- رابط کاملاً React، فارسی، RTL و واکنش‌گرا در پیشخوان
- Schema نسخه‌دار به‌عنوان منبع واحد تعریف گروه‌ها، فیلدها، مقدار پیش‌فرض و وابستگی‌ها
- ۱۷۱ تنظیم معتبر در ۲۱ گروه اصلی
- جست‌وجو بر اساس عنوان فارسی، شناسه فنی و توضیحات
- فیلدهای شرطی با قواعد equals، not_equals، contains، AND و OR
- ذخیره از REST API با nonce، capability check و اعتبارسنجی سمت سرور
- تشخیص و جلوگیری از بازنویسی هم‌زمان تنظیمات در دو پنجره
- پیش‌نویس خودکار با فاصله قابل تنظیم
- تاریخچه نسخه‌ها و بازگردانی
- پیش‌تنظیم‌های مینیمال، شرکتی، فروشگاهی و حداکثر کارایی
- خروجی و درون‌ریزی JSON نسخه‌دار
- بازنشانی یک گروه یا همه تنظیمات
- مهاجرت خودکار سه تنظیم استیج اول بدون از دست‌دادن انتخاب کاربر

1. عمومی و نحوه رندر

8. وبلاگ و نوشته تکی
9. نمونه‌کار
10. فروشگاه، محصول متغیر، برند و برچسب
11. آرشیو محصول، شبکه، فیلتر و Sidebar
12. محصول تکی، گالری، تب، نظر و محصولات مرتبط
13. ابزارهای فروش، هدیه، ارسال رایگان، تحویل، سبد رهاشده و ردیاب قیمت
14. سبد خرید، پرداخت و صفحه تشکر

## انواع فیلد

موتور فرم از text، URL، secret، textarea، number، range، switch، select، multi-select، button group، color، gradient، typography، media، icon، repeater، sortable list و code editor پشتیبانی می‌کند.

## تنظیمات اعمال‌شده در سایت

در این نسخه تنظیمات زیر مستقیماً روی خروجی قالب اعمال می‌شوند:

- رنگ‌های اصلی، متن، کادر و پس‌زمینه
- عرض کانتینر و محتوا و گردی کادرها
- فونت متن و عنوان و فونت سفارشی
- بنر بالای سایت در رندر کلاسیک و React
- متن حق نشر فوتر
- CSS و JavaScript سفارشی با دسترسی مدیر
- حذف Emoji و Embedهای اضافی
- حالت تعمیر برای بازدیدکننده، با دسترسی مدیر به سایت
- تنظیمات عمومی منتخب در Bootstrap برنامه React

تنظیماتی که به هدر/فوتر ساز، صفحه‌ساز یا ویجت‌های ووکامرس وابسته‌اند در استیج‌های ۳ تا ۵ توسط همان Schema مصرف خواهند شد.

## ارتقا از استیج اول

ZIP قالب و افزونهٔ نسخه جدید را روی نسخه قبلی جایگزین کنید. در اولین اجرا:

- تنظیمات حالت رندر، حفاظت صفحه‌سازها و انواع محتوای React مهاجرت می‌کنند.
- انتخاب مستقل React یا WordPress هر صفحه حفظ می‌شود.
- تنظیمات جدید با مقدارهای امن پیش‌فرض ایجاد می‌شوند.

## بسته‌های نصب

فرمان `npm run package` سه فایل می‌سازد:

- `woact-theme-0.2.0-rc1.zip`
- `woact-core-0.2.0-rc1.zip`
- `woact-stage2-0.2.0-rc1.zip`

## معیار پذیرش

- صفحه تنظیمات بدون refresh بین گروه‌ها حرکت کند.
- جست‌وجو و وابستگی فیلدها درست کار کند.
- ورودی نامعتبر در سرور پاک یا به محدوده مجاز برگردانده شود.
- ذخیره هم‌زمان ناسازگار با خطای 409 متوقف شود.
- پیش‌نویس، تاریخچه، Restore، Import، Export و Reset قابل استفاده باشند.
- تنظیمات استیج اول پس از ارتقا باقی بمانند.
- ZIPها بدون Node.js روی WordPress اجرا شوند.
