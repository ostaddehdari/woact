# استیج ۳ Woact — هدر و فوتر ساز React

نسخهٔ این استیج `0.3.0-rc1` است. این نسخه یک سازندهٔ بصری مستقل از Elementor برای هدر و فوتر اضافه می‌کند و خروجی آن در صفحات React و صفحات کلاسیک/Elementor با Runtime مشترک React نمایش داده می‌شود.

## قابلیت‌ها

- ساخت چند هدر و فوتر با عنوان، اولویت و وضعیت فعال
- سند JSON نسخه‌دار با Row، Column، Element، Style و Visibility
- جداسازی کامل Draft و Published
- Canvas کشیدن و رهاکردن و افزودن سریع با کلیک
- افزودن ردیف‌های یک تا چهار ستونه
- انتقال عناصر میان ستون‌ها، تکثیر و حذف
- جابه‌جایی ردیف، Undo و Redo محلی
- Inspector جداگانه برای سند، ردیف، ستون و عنصر
- پیش‌نمایش Desktop، Tablet و Mobile
- مخفی‌سازی مستقل ردیف و عنصر در هر دستگاه
- ذخیره خودکار پیش‌نویس و جلوگیری از بازنویسی هم‌زمان
- انتشار، تاریخچه انتشار و Restore
- تکثیر، Import و Export قالب JSON
- پیش‌نمایش واقعی در iframe هم‌مبدأ
- شروط نمایش و عدم نمایش برای کل سایت، صفحه اصلی، صفحات تکی، آرشیو، نوع محتوا و وضعیت ورود کاربر

## عناصر نسخه اول

### عمومی

لوگو، منو، جست‌وجو، دکمه، متن، HTML امن، آیکون، شبکه اجتماعی، زبان و Breadcrumb.

### چیدمان

Spacer و Divider، ردیف تمام‌عرض یا داخل کانتینر، ارتفاع، Gap، رنگ، Sticky و Overlay.

### فروشگاه و کاربر

حساب کاربری، سبد خرید و شمارنده واقعی WooCommerce، علاقه‌مندی، مقایسه و دسته‌بندی محصولات. در نبود WooCommerce پیوندهای امن fallback استفاده می‌شوند.

### فوتر

حق نشر پویا، خبرنامه، اطلاعات تماس، نماد اعتماد، روش‌های پرداخت و ناحیه ابزارک.

## مسیر مدیریت

پس از فعال‌سازی افزونه، از پیشخوان وردپرس وارد مسیر زیر شوید:

`Woact ← هدر و فوتر ساز`

دو پیش‌نویس آماده برای هدر و فوتر ایجاد می‌شود، اما برای جلوگیری از تغییر ناگهانی سایت پس از ارتقا غیرفعال می‌مانند. قالب تازه یا پیش‌فرض تا انتخاب «انتشار» روی سایت دیده نمی‌شود.

## سازگاری با Elementor

صفحات محافظت‌شدهٔ Elementor همچنان با HTML و CSS اصلی Elementor رندر می‌شوند. فقط ناحیه هدر و فوتر قالب Woact به Root مستقل React متصل می‌شود؛ بنابراین محتوای Elementor تبدیل یا دستکاری نمی‌شود.

## معیار پذیرش

- ساخت، ویرایش، تکثیر و حذف چند قالب بدون refresh کامل صفحه
- ذخیره Draft بدون تغییر خروجی منتشرشده
- انتشار و بازگردانی نسخه قبلی
- رندر یکسان JSON در پیش‌نمایش و سایت
- تغییر خودکار Visibility در breakpointهای واقعی
- حفظ رندر صفحات Elementor و Gutenberg
- نمایش داده واقعی منو، لوگو، کاربر و سبد WooCommerce
- عبور آزمون‌های PHP/JavaScript، PHP lint و تولید ZIP در CI
