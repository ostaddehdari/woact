React-first WordPress theme with progressive compatibility for Elementor, Gutenberg, WooCommerce and classic plugin output.

== Installation ==

1. Install and activate the Woact theme.
2. Install and activate the companion Woact Core plugin.
3. Open Woact in the WordPress dashboard.
4. Keep Hybrid mode enabled while migrating existing pages.

== Render modes ==

Classic: WordPress and page builders render every route.
Hybrid: WordPress remains the default and React is enabled per page.
React: Selected public post types use React while builder documents remain protected.
